## Сизга қолган қадамлар (аккаунт, логин ёки тўлов талаб қилади — мен бажармадим)

1. **PR'ни бирлаштиринг** ва Render'да янги версия жойлашганини текширинг (Render ўзи қайта йиғади).
2. **Render → Disks:** доимий диск уланганини текширинг (`DATA_DIR=/var/data`). Усиз юкланган pitch deck PDF'лари ва сўровнома жавоблари қайта ишга тушганда ўчиши мумкин (база GitHub захирасидан тикланади, PDF эмас).
3. **Сўровнома:** `https://ekomun.onrender.com/?utm_source=tg#sorov` ҳаволасини ўқитувчилар ва ОТМ гуруҳларига юборинг; 50 та жавоб йиғилгач админдаги гипотезалар жадвалига қаранг.
4. **Pitch deck:** админ → «📑 Pitch deck» → `Ekomun-investor-taqdimot.pdf` ни юкланг ва ҳар бир инвесторга ҳавола яратинг.
5. **Product Hunt:** producthunt.com да аккаунт очинг (Google/X билан), профилни тўлдиринг, 1–2 ҳафта бошқа маҳсулотларга изоҳ ёзиб фаол бўлинг, кейин «Submit» → PRODUCT-HUNT.md даги матнлар.
6. **Typefully:** typefully.com да X ва LinkedIn аккаунтларини уланг (бепул режа етарли), TYPEFULLY-30-KUN.md даги постларни навбатга қўйинг.
7. **StartupBase:** startupbase.uz да рўйхатдан ўтинг (OneID), «Digital Startups Program» ёки R&D ваучер аризасини STARTUPBASE.md даги матнлар билан тўлдиринг; жамоа маълумотларини ўзингиз ёзинг.
8. **BrowserStack (ихтиёрий):** ҳақиқий iPhone Safari'да бир марта текшириш учун бепул синов муддати; ёки оддийроғи — ўз ёки дўстингизнинг iPhone'ида сайтни очиб кўринг.
9. **Tally / Hotjar / DocSend аккаунтлари керак эмас** — улар платформа ичида қурилди.
