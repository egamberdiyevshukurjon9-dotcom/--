# Pitch deck'ни кузатиладиган ҳавола билан юбориш (DocSend ўрнига)

DocSend пулли (ойига $10 дан) ва карта талаб қилади. Ekomun серверида унинг асосий вазифаси энди бор.

## Қандай ишлатилади

1. Бошқарув маркази → **📑 Pitch deck**.
2. «1. Тақдимот (PDF)» — `Ekomun-investor-taqdimot.pdf` ни юкланг (30 МБ гача; `DECK_MAX_MB` билан ўзгартириш мумкин).
3. «2. Инвестор учун ҳавола» — кимга беришингизни ёзинг (масалан «UzVC — Азиз Каримов»), почта сўраш, юклаб олиш рухсати ва муддатни танланг → **Ҳавола яратиш**. Ҳавола нусхаланади: `https://ekomun.onrender.com/d/…`
4. Ҳар бир инвесторга **алоҳида** ҳавола беринг — шунда ким қизиққанини аниқ кўрасиз.
5. 📊 тугмаси: ким, қачон, қайси қурилмадан очди, жами қанча вақт, нечанчи саҳифагача етди, ҳар бир саҳифада ўртача вақт. Ҳаволани истаган вақт «Ёпиш» мумкин.

## Нимага эътибор бериш

- Инвестор молия (xlsx) ёки «сўралаётган сумма» саҳифасида узоқ турса — қизиқиш юқори, 24 соат ичида ёзинг.
- 2–3 саҳифада тўхтаган бўлса — бошидаги слайдлар кучсиз, уларни қисқартиринг.
- Кўришлар бўлмаса — ҳавола хатда ёки Telegram'да йўқолган, эслатма юборинг.

## Чекловлар (ҳалол)

- PDF сервер дискида сақланади: Render'да **Persistent Disk** уланган бўлиши керак, акс ҳолда қайта ишга тушганда файл ўчади (админда «файл серверда йўқ» деб кўрсатилади — қайта юкланг). GitHub захираси фақат маълумотлар базасини сақлайди, PDF'ни эмас.
- Юклаб олиш ўчирилган бўлса ҳам, ўжар одам экран суратини олиши мумкин (DocSend'да ҳам шундай).
- Кўрувчи саҳифасида «муаллиф саҳифа вақтини кўради» деган очиқ огоҳлантириш бор.
