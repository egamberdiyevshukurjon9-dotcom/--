# Қурилмалар синови (BrowserStack ўрнига)

BrowserStack пулли ва аккаунт талаб қилади. Ўрнига `tools/device-test.js` ёзилди: Playwright (Chromium) билан платформани 8 та қурилма профилида, иккала босқичда (мактаб, университет) ва ёруғ/тунги мавзуда очиб, **ҳар бир бўлимни** текширади.

| Профил | Экран |
|---|---|
| Samsung Galaxy A (Android Chrome) | 360×780 |
| Xiaomi Redmi / Pixel | 393×851 |
| iPhone SE (Safari UA) | 320×568 |
| iPhone 15 (Safari UA) | 393×659 |
| Android планшет | 712×1138 |
| iPad | 810×1080 |
| Ноутбук | 1366×768 |
| Монитор (тунги мавзу) | 1920×1080 |

Текширилади: саҳифа энига сиғиши (айбдор элемент номи билан), JavaScript ва консол хатолари, юкланмай қолган файллар, телефонда 24×24 px дан кичик тугмалар.

## Натижа (2026-10-26)

- **Биринчи ишга туширишда 109 муаммо топилди:**
  - 1440 px дан кенг экранда (1920×1080) юқори менюдаги бўлимлар кўпайиб, юқори панел экрандан 1150 px гача чиқиб кетарди — бутун саҳифа ёнга сурилар эди (71 бўлимда).
  - iPhone SE (320 px) да университет босқичида юқори панел 25 px чиқиб кетарди; «Курслар» карталари экранга сиғмас эди.
- **Тузатилди:** кенг экранда меню панел ичида ёнга суриладиган тасмага айланди; 320–360 px да профил тугмасида фақат белги қолади; курс, аудитория ва янгилик карталари тор экранга мослашади; видео бўлимидаги ҳаволалар ва мақола қидируви бармоқ учун каттайтирилди.
- **Такрорий синов: 584 текширув, 0 муаммо.**
- Қолган кичик огоҳлантиришлар (муҳим эмас): Сайёра саломатлиги харитасидаги нуқталар (SVG), Leaflet харита муаллифлик ҳаволаси.

## Ишлатиш

```bash
npm run test:devices                                   # ўзи сервер ишга туширади
node tools/device-test.js https://ekomun.onrender.com  # жойлаштирилган сайтни
SECTIONS=bosh,video DEVICES=iphone-se,fullhd SHOTS=1 node tools/device-test.js
```

Ҳисобот: `tools/out/device-report.md` ва `.json`, `SHOTS=1` бўлса скриншотлар.

**Чеклов:** бу Chromium мотори; ҳақиқий Safari (WebKit) ва Firefox текширилмайди. Ҳақиқий iPhone'да синаш учун BrowserStack'нинг бепул синов муддати (Live, 100 дақиқа) ёки ўз телефонингиз — пастдаги рўйхатга қаранг.
