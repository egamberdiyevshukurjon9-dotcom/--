# 🌿 ЭкоТаълим

Экология йахшилаш учун очиқ таълим платформаси: аҳоли, корхоналар ва мактаб/олийгоҳлар учун интерактив дарслар, эко-кутубхона, Ўзбекистон шаҳарлари бўйича жонли ҳаво сифати, углерод изи калькулятори, кунлик эко-челленж ва эко-ёрдамчи.

## Эко-ўйинлар

Болалар учун 4 та ўйин (`#oyinlar` бўлими): **Чиқиндини сарала**, **Эко-хотира**, **Тўғри ёки нотўғри?** ва **Менинг дарахтим**. Ўйинлар интернетсиз ва ҳисобсиз ишлайди, натижалар қурилмада сақланади, XP ва нишонлар беради (бир ўйиндан кунига 3 мартагача XP).

Болалар хавфсизлиги: реклама ва кузатувчилар йўқ, ташқи шрифтлар ишлатилмайди, ҳисоб очишда нейтрал ёш сўрови бор — 13 ёшга тўлмаганлар ҳисоб оча олмайди (сервер ҳам текширади, туғилган йил сақланмайди).

## Эко-кўз (расм орқали экологик таҳлил)

`#ekokoz` бўлими: фойдаланувчи манзарани суратга олади ёки галереядан танлайди, сервер расмни Claude API (`claude-opus-5-5`, расм + JSON жавоб схемаси) орқали фақат экологик нуқтаи назардан таҳлил қилади: нима кўриняпти, хавф даражаси, таъсири, маслаҳатлар ва қаерга мурожаат қилиш.

- Фақат ҳисобга кирган **18+** фойдаланувчилар учун; ҳар сафар огоҳлантириш ва розилик белгиси.
- Расм браузерда 1280 px гача кичрайтирилади (EXIF/GPS ўчади), серверда сақланмайди.
- Чекловлар: расм ≤ 3 МБ, бир фойдаланувчи кунига `AI_USER_DAILY_LIMIT` (10), бутун сайт `AI_GLOBAL_DAILY_LIMIT` (300).
- Созлаш: Render'да `ANTHROPIC_API_KEY` (махфий). Ихтиёрий: `ANTHROPIC_MODEL`.
- Тахминий нарх: бир расм учун ≈ $0.02–0.04 (Opus 5.5: $4 / $20 1M токен учун).

## Админ панел

`/admin` саҳифасида кўринади:

- **Ҳозир сайтда** — ҳозир платформада бўлган фойдаланувчилар (қурилмаси ва IP манзили билан).
- **Ким кирди, ким чиқди** — рўйхатдан ўтиш, кириш, чиқиш, саҳифани ёпиш ва хато парол уринишлари журнали. Исм/почта ва ҳодиса тури бўйича қидириш мумкин.
- **Фойдаланувчилар** — барча ҳисоблар, охирги кириш вақти ва киришлар сони.
- Бугунги кўрсаткичлар. Панел ҳар 15 сонияда ўзи янгиланади.

Фойдаланувчи «Чиқиш» тугмасини босса — «Чиқди», саҳифани ёпиб кетса — 3 дақиқадан сўнг «Саҳифани ёпди» деб ёзилади.

## Ишга тушириш

Node.js 18 ёки янгироғи керак. Ташқи кутубхоналар ўрнатиш шарт эмас.

```bash
ADMIN_PASSWORD="кучли-парол" node server.js
```

- Платформа: http://localhost:3000
- Админ панел: http://localhost:3000/admin

| Ўзгарувчи | Маъноси | Асл қиймат |
|---|---|---|
| `ADMIN_PASSWORD` | Админ панел пароли (мажбурий) | — |
| `PORT` | Порт | `3000` |
| `DATA_DIR` | Маълумотлар сақланадиган папка | `./data` |
| `ONLINE_MINUTES` | Неча дақиқа жимликдан сўнг «чиқди» ҳисобланади | `3` |
| `SESSION_DAYS` | Кириш неча кун эсда қолади | `30` |

Маълумотлар `data/db.json` файлида сақланади (пароллар хэшланган ҳолда). Бу папка репозиторийга юкланмайди.

## Интернетга чиқариш (Render)

Кириш/чиқишни қайд этиш учун сервер керак, шунинг учун **GitHub Pages етарли эмас**. Репозиторийда Render учун тайёр `render.yaml` бор.

1. https://dashboard.render.com га GitHub орқали киринг.
2. **New → Blueprint** ни босинг ва шу репозиторийни танланг.
3. Render `ADMIN_PASSWORD` ни сўрайди — админ панел учун кучли парол ёзинг.
4. **Deploy Blueprint** ни босинг. Бир неча дақиқадан сўнг сайт `https://ekotalim-….onrender.com` манзилида очилади, админ панел — `/admin` да.

**Бепул режим чекловлари:** 15 дақиқа ҳеч ким кирмаса сервер «ухлайди» ва кейинги очилишда ~1 дақиқа кутилади; сервер қайта ишга тушганда фойдаланувчилар ва кириш журнали ўчиб кетади. Маълумотлар сақланиши учун пулли режим (Starter) ва доимий диск керак — `render.yaml` ичидаги изоҳдаги қаторларни очинг.

`index.html` ни серверсиз очса ҳам платформа ишлайди, фақат «Кириш» тугмаси кўринмайди.

## Google Play'га чиқариш

Сайт ўрнатиладиган илова (PWA) сифатида тайёр: `manifest.webmanifest`, `sw.js` (интернетсиз ҳам очилади), `icons/` ва махфийлик сиёсати (`/privacy`). Android иловаси сайтни Trusted Web Activity орқали очади — алоҳида код ёзиш шарт эмас.

1. Сайт Render'да HTTPS манзилда ишлаётган бўлсин (масалан `https://ekotalim-xxxx.onrender.com`).
2. https://www.pwabuilder.com га шу манзилни киритинг → **Package for stores → Android → Generate**. Package ID: `uz.ekotalim.app`.
3. Юклаб олинган архивда `.aab` файл, имзо калити (`signing.keystore`, паролларини сақлаб қўйинг!) ва `assetlinks.json` бўлади.
4. Play Console'да илова яратинг, `.aab` ни юкланг. **App integrity → App signing** бўлимидаги **SHA-256** изини Render'даги `ANDROID_SHA256` ўзгарувчисига ёзинг (PWABuilder калитининг изи ҳам бўлса, вергул билан иккаласини). Шунда `/.well-known/assetlinks.json` ишлайди ва илова манзил сатрисиз очилади.
5. Store listing учун махфийлик сиёсати манзили: `https://…onrender.com/privacy`. Ҳисобни ўчириш иловада бор (исм → «Ҳисобни ўчириш»).

`ANDROID_PACKAGE` (асл қиймат `uz.ekotalim.app`) ва `CONTACT_EMAIL` ҳам Render'да созланади.
