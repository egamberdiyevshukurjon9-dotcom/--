# 🌿 ЭкоТаълим

Экология йахшилаш учун очиқ таълим платформаси: аҳоли, корхоналар ва мактаб/олийгоҳлар учун интерактив дарслар, эко-кутубхона, Ўзбекистон шаҳарлари бўйича жонли ҳаво сифати, углерод изи калькулятори, кунлик эко-челленж ва эко-ёрдамчи.

## Админ панел

`/admin` саҳифасида кўринади:

- **Ҳозир сайтда** — ҳозир платформада бўлган фойдаланувчилар (қурилмаси ва IP манзили билан).
- **Ким кирди, ким чиқди** — рўйхатдан ўтиш, кириш, чиқиш, саҳифани ёпиш ва хато парол уринишлари журнали. Исм/почта ва ҳодиса тури бўйича қидириш мумкин.
- **Фойдаланувчилар** — барча ҳисоблар, охирги кириш вақти ва киришлар сони.
- Бугунги кўрсаткичлар. Панел ҳар 15 сонияда ўзи янгиланади.

Фойдаланувчи «Чиқиш» тугмасини босса — «Чиқди», саҳифани ёпиб кетса — 3 дақиқадан сўнг «Саҳифани ёпди» деб ёзилади.

## Ишга тушириш

Node.js 18 ёки янгироғи керак. Ташқи кутубхоналар ўрнатиш шарт эмас.

```bash
ADMIN_PASSWORD="кучли-парол" node server.js
```

- Платформа: http://localhost:3000
- Админ панел: http://localhost:3000/admin

| Ўзгарувчи | Маъноси | Асл қиймат |
|---|---|---|
| `ADMIN_PASSWORD` | Админ панел пароли (мажбурий) | — |
| `PORT` | Порт | `3000` |
| `DATA_DIR` | Маълумотлар сақланадиган папка | `./data` |
| `ONLINE_MINUTES` | Неча дақиқа жимликдан сўнг «чиқди» ҳисобланади | `3` |
| `SESSION_DAYS` | Кириш неча кун эсда қолади | `30` |

Маълумотлар `data/db.json` файлида сақланади (пароллар хэшланган ҳолда). Бу папка репозиторийга юкланмайди.

## Интернетга чиқариш (Render)

Кириш/чиқишни қайд этиш учун сервер керак, шунинг учун **GitHub Pages етарли эмас**. Репозиторийда Render учун тайёр `render.yaml` бор.

1. https://dashboard.render.com га GitHub орқали киринг.
2. **New → Blueprint** ни босинг ва шу репозиторийни танланг.
3. Render `ADMIN_PASSWORD` ни сўрайди — админ панел учун кучли парол ёзинг.
4. **Deploy Blueprint** ни босинг. Бир неча дақиқадан сўнг сайт `https://ekotalim-….onrender.com` манзилида очилади, админ панел — `/admin` да.

**Бепул режим чекловлари:** 15 дақиқа ҳеч ким кирмаса сервер «ухлайди» ва кейинги очилишда ~1 дақиқа кутилади; сервер қайта ишга тушганда фойдаланувчилар ва кириш журнали ўчиб кетади. Маълумотлар сақланиши учун пулли режим (Starter) ва доимий диск керак — `render.yaml` ичидаги изоҳдаги қаторларни очинг.

`index.html` ни серверсиз очса ҳам платформа ишлайди, фақат «Кириш» тугмаси кўринмайди.
