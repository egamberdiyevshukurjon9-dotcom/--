# 🌿 Ekomun

Экология йахшилаш учун очиқ таълим платформаси: аҳоли, корхоналар ва мактаб/олийгоҳлар учун интерактив дарслар, эко-кутубхона, Ўзбекистон шаҳарлари бўйича жонли ҳаво сифати, углерод изи калькулятори, кунлик эко-челленж ва эко-ёрдамчи.

> Илова номи 2026-йил октябрдан **Ekomun** (аввалги номи ЭкоТаълим). Android пакет номи `uz.ekotalim.app` ва имзо калити ўзгармаган, шунинг учун ўрнатилган илова устидан янгиланади; қурилмадаги `ekotalim:*` калитлари ҳам сақланган, фойдаланувчи натижалари йўқолмайди.

## Стартап воситалари: сўровнома, UX харита, pitch deck (`startap.js`)

Tally, Hotjar ва DocSend ўрнига платформа ичидаги воситалар: `#sorov` сўровномаси (`vendor/eko-sorov.js`), аноним клик ва айланиш таҳлили (`vendor/eko-ux.js`), инвестор учун `/d/<калит>` тақдимот ҳаволалари (`deck.html`, `vendor/eko-deck.js`); админда «Сўровнома», «UX харита», «Pitch deck» бўлимлари (`admin/startap.js`). Қурилмалар синови: `npm run test:devices`. Бозор таҳлили ва launch материаллари: [`startap/`](startap/README.md).

## Ўйин маркази ва Такрорлаш хонаси (`vendor/eko-oyin.js`)

- **🏆 Ўйин маркази** (`#oyinmarkaz`): 60 та даража (8 босқич: Уруғ → Сайёра қоровули), кунлик кириш серияси ва «🧊 серия ҳимояси», кунлик/ҳафталик/мавсумий вазифалар, яшил тангалар ва эко-дўкон (аватар, профил фони), ҳар курс учун «Ифлосланиш боши» босс жанги.
- **🧠 Такрорлаш хонаси** (`#takror`): SM-2 карталари (1 → 3 → 7 → 16 → 35 кун), аралаш машқ (турли курслардан 10 савол) ва хатолар дафтари (ҳафталик диаграмма билан).
- XP: дарс +50, тестда 90%+ +30 / 100% +50, кроссворд +40, 3D лаб +60, ҳашар +100, сертификат +200, кунлик кириш +10. Нишонлар: 60 та (яширинлари билан).
- Ҳолат `localStorage["ekotalim:game"]` да сақланади.

## Экологик ҳуқуқ (`vendor/eko-qonun.js`, `vendor/eko-qonun-data.js`)

Университет босқичи учун `#qonun` бўлими: Конституциянинг экологик моддалари (49, 61, 62, 66, 68, 79, 115, 123), 22 та қонун карточкаси (12 мавзу, қидирув), экологик суд (moot court), кейс-стади, Оксфорд дебати, эко-детектив, корхона симулятори, хорижий очиқ маълумот платформалари ва тест. Ҳуқуқий маълумот `eko-qonun-data.js` да, ҳолати `ASOF` майдонида; янгилашда ҳар бир карточкадаги lex.uz ҳаволаси бўйича охирги таҳрирни солиштиринг.

## Дарсни PDF қилиш (`vendor/eko-pdf.js`)

Ҳар бир дарсдаги «PDF» тугмаси экрандаги (таржима қилинган) матндан A4 PDF тузади: матн танланади, ҳаволалар босилади, охирида жавоблар калити. jsPDF (MIT) ва Liberation Sans қисми «Ekomun PDF Sans» (SIL OFL) `vendor/pdf/` да; биринчи босилганда юкланади ва интернетсиз ҳам ишлайди. Блокни PDF дан чиқариш учун `data-pdf-skip` атрибути.

## Эко-ўйинлар

Болалар учун 4 та ўйин (`#oyinlar` бўлими): **Чиқиндини сарала**, **Эко-хотира**, **Тўғри ёки нотўғри?** ва **Менинг дарахтим**. Ўйинлар интернетсиз ва ҳисобсиз ишлайди, натижалар қурилмада сақланади, XP ва нишонлар беради (бир ўйиндан кунига 3 мартагача XP).

Болалар хавфсизлиги: реклама ва кузатувчилар йўқ, ташқи шрифтлар ишлатилмайди, ҳисоб очишда нейтрал ёш сўрови бор — 13 ёшга тўлмаганлар ҳисоб оча олмайди (сервер ҳам текширади, туғилган йил сақланмайди).

## Финляндия усулида дарслар ва кроссвордлар

Курслар Финляндия таълим тамойилларига мосланган: ҳар бир дарс 🎯 мақсад, 🤔 ҳаётий савол (феномен), қисқа матн ёки «🧒 Осон тилда» варианти, 🤲 амалий топшириқ, 🧩 мини-кроссворд, стрессиз тест (хато жавобдан кейин яна танлаш мумкин), 🪞 ўз-ўзини баҳолаш ва ☕ танаффус таклифидан иборат. «Aa» тугмаси матнни катталаштиради.

- «Кичик эколог» — 6–10 ёшли болалар учун янги курс («Болалар» фильтри).
- «📖 Дарслик» — курсни китоб каби бир саҳифада ўқиш, чоп этиш ёки HTML файл қилиб юклаб олиш.
- `#krossvord` — 8 та мавзули кроссворд (Осон, Ўрта, Қийин). Тўр ҳар бир алифбода алоҳида тузилади: лотинда sh, ch, oʻ, gʻ битта катак.
- Дарс маълумотлари (`LESSON_PLUS`, `CROSSWORDS`) `index.html` ичида, курслар рўйхатидан кейин.

## Эко-кўз (расм орқали экологик таҳлил)

`#ekokoz` бўлими: фойдаланувчи манзарани суратга олади ёки галереядан танлайди, сервер расмни Claude API (`claude-opus-5-5`, расм + JSON жавоб схемаси) орқали фақат экологик нуқтаи назардан таҳлил қилади: нима кўриняпти, хавф даражаси, таъсири, маслаҳатлар ва қаерга мурожаат қилиш.

- Фақат ҳисобга кирган **18+** фойдаланувчилар учун; ҳар сафар огоҳлантириш ва розилик белгиси.
- Расм браузерда 1280 px гача кичрайтирилади (EXIF/GPS ўчади), серверда сақланмайди.
- Чекловлар: расм ≤ 3 МБ, бир фойдаланувчи кунига `AI_USER_DAILY_LIMIT` (10), бутун сайт `AI_GLOBAL_DAILY_LIMIT` (300).
- Созлаш: Render'да `ANTHROPIC_API_KEY` (махфий). Ихтиёрий: `ANTHROPIC_MODEL`.
- Тахминий нарх: бир расм учун ≈ $0.02–0.04 (Opus 5.5: $4 / $20 1M токен учун).

### Мурожаат матни

Эко-кўз натижасида «✉️ Мурожаат матни» тугмаси бор: СИ таҳлилдан ҳокимият ёки pm.gov.uz учун расмий хат тузади (`POST /api/appeal`, матнли Claude сўрови). Исм, манзил ва телефон ўрнида `[квадрат қавс]` қолади — фойдаланувчи ўзи тўлдириб, ўзи юборади. Кунлик СИ чекловига киради, фақат 18+.

## Эко-харита

`#xarita` бўлими: фойдаланувчи (13+ ҳисоб) муаммони (ахлатхона, ахлат ёқиш, тутун, кесилган дарахт, сув ифлосланиши) харитада белгилайди. Хабар аввал админ панелда **модерация**дан ўтади, фақат тасдиқлангани оммага кўринади (муаллифсиз, ~100 м аниқликда).

- Тасдиқланган ҳар бир хабар учун муаллифга **+20 XP** ва «🛡️ Эко-патрул» нишони.
- Харита: Leaflet (`vendor/leaflet`, BSD-2) ўз серверимиздан, OpenStreetMap тайллари. Интернет бўлмаса ҳам Ўзбекистон чегараси (`vendor/uz-border.json`, Natural Earth) ва шаҳарлар кўринади.
- Чеклов: бир фойдаланувчи кунига `REPORTS_DAILY_LIMIT` (5) та хабар. Координаталар Ўзбекистон ичида бўлиши шарт.
- Эко-кўз натижасидан «📍 Харитада белгилаш» — тур ва матн ўзи тўлдирилади.

## Ҳашар: олдин ва кейин

`#hashar` бўлими: иккита расм телефоннинг ўзида бир расмга бирлаштирилади (сана, жой номи, «ОЛДИН/КЕЙИН» белгилари). Юклаб олиш ёки улашиш мумкин. Ҳеч нарса серверга юборилмайди. Кунига бир марта +10 XP.

## Мактаблар учун

`#maktab` бўлими:

- **Ўқитувчи** (18+ ҳисоб) синф очади — 6 белгили синф коди берилади. Эко-топшириқлар: XP тўплаш, «Чиқиндини сарала» ва викторинада балл, «Эко-хотира», дарахтга сув бериш, курсни тугатиш, челленж серияси; муддат қўйиш мумкин. Ўқувчилар жадвали: XP, бажарилган топшириқлар, охирги фаоллик.
- **Ўқувчи** ҳисоб очмайди: код ва лақаб билан қўшилади. Натижалар қурилмадан ўзи ҳисобланиб, серверга фақат лақаб, XP ва рақамлар юборилади. Синф рейтинги (фақат лақаблар).

## Бошқарув маркази (алоҳида админ сайт)

Платформадан алоҳида, фақат эгаси учун очиладиган сайт (`admin/`). Асосий сайтда унга ҳеч қандай ҳавола йўқ, қидирув тизимларига ёпиқ (`noindex`), бошқа сайт ичида очилмайди.

- **Умумий ҳолат** — ҳозир онлайн, бугун кирганлар, янгилар, ўртача ташриф вақти, кунлик график, **нима мақсадда** фойдаланишмоқда (ўқиш, ўйин, лаборатория, амалий иш, маълумот, синф), энг кўп вақт ўтказилган бўлимлар, босқич ва ёш гуруҳи.
- **Ҳозир онлайн** — ҳисоби борлар ва барча фаол қурилмалар: ҳозир қайси бўлимда, қайси бўлимлардан ўтди, қанча вақтдан бери, қурилма, IP. Ҳар 15 сонияда янгиланади.
- **Фойдаланувчилар** — ҳисоблар ва меҳмонлар (қурилма коди билан); ҳар бирининг тафсилоти: барча ташрифлари, кирди-чиқди вақтлари, қайси мақсадда ва қайси бўлимларда қанча вақт ўтказгани.
- **Кирди-чиқди** — ҳисоблар журнали (рўйхатдан ўтди, кирди, чиқди, хато парол, блок) ва ташрифлар (кирди, чиқди, нималар қилди). CSV (Excel) юклаб олиш.
- **Статистик таҳлил** — 1/7/30/90/180 кун: кунлик динамика, ҳафта куни × соат иссиқлик харитаси, ташриф давомийлиги, бўлимлар ва дарслар рейтинги, тил, тизим, браузер ва автоматик хулосалар.
- **Блок ва хавфсизлик** — ҳисоб, қурилма ёки IP манзилни **блоклаш** (сабаби билан) ва блокдан чиқариш; ҳисобни ва унинг барча маълумотларини **платформадан ўчириш**; шубҳали фаоллик (кўп хато парол, кўп ҳисоб, жуда кўп сўров); бошқарув марказига ҳар бир кириш уриниши журнали.
- **Ўсиш ва ўқиш** — DAU/WAU/MAU, DAU/MAU, ўртача сессия, дарҳол чиқиб кетганлар; воронка (кирди → профил → дарс очди → тугатди → якуний тест → ўтди → сертификат); қайтиш (1+/7+/30+ кун); ҳафталик когорталар; ҳар бир дарс: очилди, тугатилди, ўртача вақт; энг кўп хато қилинадиган саволлар; берилган сертификатлар.
- **Таҳлил ва ҳисобот** — барча фойдаланувчилар (ҳисоб ва меҳмонлар) таҳлили: фаоллик сегментлари (фаол, сусайган, кетиш хавфи, нофаол), 0–100 фаоллик балли, босқич, ёш, ҳудуд, қурилма, ўқиш воронкаси, эътибор талаб қиладиганлар ва автоматик хулосалар. Давр ва филтрлар бўйича **PDF** ва **Word (DOCX)** ҳисобот (сервер ўзи яратади, ташқи кутубхонасиз; PDF учун `fonts/` даги DejaVu Sans) ҳамда CSV.
- **Натижалар** — ҳар бир ўқувчи: нечта дарс очди ва тугатди, тест саволларига тўғри жавоблар фоизи, ҳар курс бўйича якуний тест (энг яхши натижа, уринишлар) ва сертификатлар; курслар кесимида ўқувчилар, ўртача натижа ва ўтганлар улуши. CSV (Excel).
- **Ҳудуд ва қурилма** — ҳар бир кириш ва ташрифда IP бўйича тахминий ҳудуд (вилоят ёки шаҳар, хорижда — мамлакат) ва қурилма (телефон/компьютер, модели, тизим, браузер). Умумий ҳолатда ҳудудлар ва қурилмалар графиги.
- **Эко-харита** — хабарларни тасдиқлаш, рад этиш, ўчириш.
- **Тизим ва хатолар** — сервер ҳолати, маълумотлар ҳажми, кунлик захира нусхалар (`data/backups`, охирги `BACKUP_KEEP` таси) ва ҳозирги нусхани юклаб олиш, бравзердаги JavaScript хатолари журнали (`/api/err`, шахсий маълумотсиз), uptime кузатуви учун `/api/health`.

Ёруғ / тунги мавзу тугмаси (авто → ёруғ → тунги) ён панелда; фон ва шрифт платформа билан бир хил.

Блокланган ҳисоб кира олмайди ва очиқ сессияси ёпилади; блокланган қурилма ва IP да платформа «Кириш чекланган» ойнасини кўрсатади.

**Фақат сизга очилиши учун** (Render → Environment):

| Ўзгарувчи | Нима беради |
|---|---|
| `ADMIN_PASSWORD` | Кучли парол (мажбурий) |
| `ADMIN_PATH` | Махфий манзил, масалан `/boshqaruv-7k2q` → `https://сайт/boshqaruv-7k2q/`. Асл қиймат `/admin` |
| `ADMIN_TOTP_SECRET` | Икки босқичли ҳимоя: `node tools/admin-totp.js` калит яратади, уни Google Authenticator'га қўшасиз; кириш учун парол + телефондаги 6 рақамли код керак бўлади |
| `ACCOUNT_SECRET` | Ҳисоб калити (`eko_pass` cookie) шифри. Render бепул режимида сервер ухлаб уйғонганда маълумотлар ўчади — фойдаланувчи ҳисоби шу калит орқали браузеридан ўзи тикланади. Берилмаса, `ADMIN_PASSWORD` дан ҳосил қилинади (уни ўзгартирсангиз, эски калитлар бекор бўлади) |
| `ADMIN_HOST` | Алоҳида домен, масалан `admin.ekomun.uz` (Render → Settings → Custom Domains орқали шу сервисга уланади). Берилса, бошқарув маркази фақат шу доменда очилади, асосий сайтда умуман йўқ |
| `ADMIN_ALLOW_IPS` | Фақат шу IP манзиллардан очилсин (вергул билан), ихтиёрий |

Статистика учун сайт ўз серверига анонимлаштирилган маълумот юборади (`vendor/eko-stat.js`): тасодифий қурилма коди, бўлимлар ва вақт, босқич, ёш гуруҳи, тил. Профилдаги исм юборилмайди (болалар махфийлиги); ҳисобга кирганлар исми ва почтаси билан кўринади. Ташрифлар 180 кун сақланади.

## Сертификат ва уни текшириш

Курсни тугатган фойдаланувчи сертификат олади. Серверда ишлаганда сертификат рўйхатга олинади (`POST /api/cert`) ва унга `EKM-XXXXXXXXXX` коди ҳамда `/tekshir?c=КОД` саҳифасига олиб борувчи QR код чизилади (`vendor/qrcode.js`, MIT). Ҳар ким QR ни сканер қилиб сертификат ҳақиқийлигини кўради. Интернетсиз (Android илова) сертификат маҳаллий рақам билан берилади.

Платформа пастидаги «Ekomun v2.0» — версия ва янгиликлар; «Маълумотларимни юклаб олиш» — қурилмадаги ва сервердаги (`GET /api/account/export`) ўз маълумотлари JSON файлда.

## Ишга тушириш

Node.js 18 ёки янгироғи керак.

```bash
npm install
ADMIN_PASSWORD="кучли-парол" node server.js
```

- Платформа: http://localhost:3000
- Бошқарув маркази: http://localhost:3000/admin/ (ёки `ADMIN_PATH`)

| Ўзгарувчи | Маъноси | Асл қиймат |
|---|---|---|
| `ADMIN_PASSWORD` | Бошқарув маркази пароли (мажбурий) | — |
| `ADMIN_PATH`, `ADMIN_HOST`, `ADMIN_TOTP_SECRET`, `ADMIN_ALLOW_IPS` | Бошқарув марказини яшириш ва ҳимоялаш (юқорига қаранг) | — |
| `PORT` | Порт | `3000` |
| `DATA_DIR` | Маълумотлар сақланадиган папка | `./data` |
| `ONLINE_MINUTES` | Неча дақиқа жимликдан сўнг «чиқди» ҳисобланади | `3` |
| `SESSION_DAYS` | Кириш неча кун эсда қолади | `30` |
| `ANTHROPIC_API_KEY` | Эко-кўз ва мурожаат матни учун Claude API калити (махфий) | — |
| `REPORTS_DAILY_LIMIT` | Бир фойдаланувчи кунига нечта харита хабари юбора олади | `5` |
| `BACKUP_KEEP` | Нечта кунлик захира нусха сақлансин (`data/backups`) | `14` |
| `TRUST_PROXY` | `1` бўлса, мижоз IP си `X-Forwarded-For` дан олинади (Render'да ёқилган) | — |
| `GEO_PROVIDER` | Бошқарув марказида IP бўйича ҳудуд (вилоят, шаҳар): `ipwho` ёки `off` | `ipwho` |

## Интернетга чиқариш (Render)

Кириш/чиқишни қайд этиш учун сервер керак, шунинг учун **GitHub Pages етарли эмас**. Репозиторийда Render учун тайёр `render.yaml` бор.

1. https://dashboard.render.com га GitHub орқали киринг.
2. **New → Blueprint** ни босинг ва шу репозиторийни танланг.
3. Render `ADMIN_PASSWORD`, `ADMIN_PATH` ва `ADMIN_TOTP_SECRET` ни сўрайди — кучли парол, махфий манзил ва `node tools/admin-totp.js` берган калитни ёзинг.
4. **Deploy Blueprint** ни босинг. Бир неча дақиқадан сўнг сайт `https://ekomun-….onrender.com` манзилида очилади, бошқарув маркази — сиз берган махфий манзилда.

**Бепул режим чекловлари:** 15 дақиқа ҳеч ким кирмаса сервер «ухлайди» ва кейинги очилишда ~1 дақиқа кутилади; сервер қайта ишга тушганда фойдаланувчилар ва кириш журнали ўчиб кетади. Маълумотлар сақланиши учун пулли режим (Starter) ва доимий диск керак — `render.yaml` ичидаги изоҳдаги қаторларни очинг.

`index.html` ни серверсиз очса ҳам платформа ишлайди, фақат «Кириш» тугмаси кўринмайди.

## Google Play'га чиқариш

Сайт ўрнатиладиган илова (PWA) сифатида тайёр: `manifest.webmanifest`, `sw.js` (интернетсиз ҳам очилади), `icons/` ва махфийлик сиёсати (`/privacy`). Android иловаси сайтни Trusted Web Activity орқали очади — алоҳида код ёзиш шарт эмас.

1. Сайт Render'да HTTPS манзилда ишлаётган бўлсин (масалан `https://ekomun-xxxx.onrender.com`).
2. https://www.pwabuilder.com га шу манзилни киритинг → **Package for stores → Android → Generate**. Package ID: `uz.ekotalim.app`.
3. Юклаб олинган архивда `.aab` файл, имзо калити (`signing.keystore`, паролларини сақлаб қўйинг!) ва `assetlinks.json` бўлади.
4. Play Console'да илова яратинг, `.aab` ни юкланг. **App integrity → App signing** бўлимидаги **SHA-256** изини Render'даги `ANDROID_SHA256` ўзгарувчисига ёзинг (PWABuilder калитининг изи ҳам бўлса, вергул билан иккаласини). Шунда `/.well-known/assetlinks.json` ишлайди ва илова манзил сатрисиз очилади.
5. Store listing учун махфийлик сиёсати манзили: `https://…onrender.com/privacy`. Ҳисобни ўчириш иловада бор (исм → «Ҳисобни ўчириш»).

`ANDROID_PACKAGE` (асл қиймат `uz.ekotalim.app`) ва `CONTACT_EMAIL` ҳам Render'да созланади.
